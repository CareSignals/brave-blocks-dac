# DAC Review Notes

## Intended use

Brave Blocks offers short, child-led practice for naming feelings, noticing
body signals, asking for help, preparing for meetings, choosing safe actions,
and repairing connection after a hard moment. It is designed for co-use with a
trusted support person and should be practiced while the child is regulated.

## Content safeguards

- Fictional stories come before optional personal reflection.
- A child can pass at every disclosure-adjacent moment.
- Rewards recognize participation and skill practice, never the content of an
  answer.
- Professional roles are introduced without promising confidentiality or a
  particular case outcome.
- The app does not ask a child to describe allegations, visits, placements, or
  family members.
- Loyalty, missing someone, mixed feelings, and attachment to multiple people
  are welcomed without interpretation.
- Safety language validates the feeling while keeping bodies and hands safe.

## Privacy safeguards

- No accounts, analytics, telemetry, or behavioral profiles.
- No game choices are saved or transmitted.
- An optional player name exists only in component memory and disappears when
  the session is reset or the page is closed.
- Prerecorded narration is stored with the app. Variable phrases use device
  speech when available.
- External music opens only after a deliberate tap with a no-referrer policy.

## Review questions

1. Is every role description accurate for the professional using the tool?
2. Could any prompt be heard as leading, evaluative, or disclosure-seeking?
3. Does the child understand that passing is a complete answer?
4. Are the Pause Portal choices consistent with the child’s support plan?
5. Can a five-year-old complete the core pathways by pictures and narration?
6. Are text size, focus order, touch targets, reduced motion, and contrast
   usable on the intended tablet or phone?
7. Should any words be individualized only in a private, case-specific build?
